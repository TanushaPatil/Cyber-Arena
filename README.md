# Cyber Arena 🛡️

**Cyber Arena** is a web-based cybersecurity Capture The Flag (CTF) platform where users can explore cybersecurity challenges and practise problem-solving skills in a controlled learning environment.

## Features

- User registration and login
- Cybersecurity challenges
- Hands-on learning through CTF-style tasks
- Web-based interface built with Python and Flask

## Requirements

- Python 3.10 or later
- pip (Python package installer)
- A web browser

## Download and Installation

### 1. Download the project

Download `Cyber-Arena-dist.zip` from this GitHub repository and extract it to a folder on your computer.

### 2. Open the project folder

Open a terminal or Command Prompt inside the extracted project folder containing `app.py` and `requirements.txt`.

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows:**

```bash
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Start the application

```bash
python app.py
```

### 7. Open Cyber Arena

Open your browser and visit:

http://127.0.0.1:5000

Register or log in to begin exploring the available challenges.

## Important Notes

- Run the application locally on your own computer.
- Only test cybersecurity techniques in this authorised learning environment.
- Some challenges may require additional files or configuration.
- Do not expose development settings or secret keys when deploying the application publicly.

## Troubleshooting

If Python is not recognised, install Python and ensure it is added to your system's PATH.

If dependency installation fails, check your Python and pip installations and review the error message.
