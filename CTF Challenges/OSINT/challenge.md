# The Vanishing Profile

## Scenario

A user disappeared from the internet, but several public clues
were left behind.

You have been given a photograph containing a few visual clues
about the person's last known location.

Your task is to identify the railway station and the city shown
by connecting the available public information.

## Objective

Identify:

1. The railway station
2. The city where it is located

Then submit the flag using the format provided by the platform.

## Investigation

Start by carefully examining the supplied image.

Look for:

- Railway infrastructure
- Station architecture
- Train line colors
- Signage
- Nearby landmarks
- Geographic clues
- Other visual details

You may use public search engines, maps and image-search tools
to correlate the clues.

## Recommended Tools

- Google Lens
- Google Maps
- Web Search

## Flag

Submit the flag through the Cyber Arena submission box after
identifying the location.
